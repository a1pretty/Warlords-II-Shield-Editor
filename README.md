# Warlords-II-Shield-Editor
This is a shield editor for my beloved game Warlords II. It works with version 1.02 and version 1.11 of the game (the one that comes with Scenario Builder). Sadly, this version does not work with Warlords II Deluxe.

This is an unofficial fan-made tool. Not affiliated with or endorsed by SSG, Infinite Interactive or any rights holder. Warlords is a trademark of its respective owner. You need your own copy of Warlords II to use it
